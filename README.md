# CalculadoraDeEdad

Calculadora de edad

Página hecha con HTML y JavaScript que pide nombre, apellido y año de nacimiento, calcula la edad y dice si la persona es mayor o menor de edad. Usa un ciclo while para poder repetir el cálculo varias veces.

Estructura
index.html
index.js
Cómo usarlo

Abrir index.html en el navegador y responder lo que va preguntando.

Ejemplo

Nombre: Wellington Apellido: Junior Año de nacimiento: 2005

Resultado: Wellington Junior tiene 21 años, es mayor de edad.
